# Spec: Password Toggle UX

## functional_requirements

### MODIFIED Visible Toggle
Campos `type=password` en create/unlock MUST mostrar icono visible y accionable para alternar visibilidad.

## acceptance_criteria

### ADDED Toggle Visibility
- **GIVEN** campo de password en dialog
- **WHEN** dialog renderiza
- **THEN** icono de ojo es visible en estado normal.
