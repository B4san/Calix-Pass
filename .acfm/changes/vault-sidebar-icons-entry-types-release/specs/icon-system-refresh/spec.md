# Spec: Icon System Refresh

## functional_requirements

### ADDED SaaS Icon Pack
La aplicación MUST usar una librería de iconos moderna y consistente para UI de vaults y sidebar.

### MODIFIED No Emoji Vault Icons
La UI de vaults MUST reemplazar emojis por iconos vectoriales.

## acceptance_criteria

### ADDED Icon Consistency
- **GIVEN** vistas de picker/sidebar
- **WHEN** app renderiza
- **THEN** iconos provienen del paquete adoptado y no de emojis.
